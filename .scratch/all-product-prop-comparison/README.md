# 全商品 Prop Firm 條款比較（TradingPilot 全目錄）

**檢索日：2026-08-11**｜**範圍：** TradingPilot 首頁當時列出的 35 家跨 Forex／CFD／股票／期貨／Crypto prop firm。TradingPilot 只用於取得候選清單與觀察其 payout tracker；所有費用、規則與限制均以各業者官方頁面為依據。

> **重要限制：** TradingPilot 的 payout tracker 當日顯示「0 payouts / 0 firms tracked」，並且只追蹤 Rise payouts。因此本研究**沒有可用的獨立 payout 歷史、拒付率或支付成功率**。下列「Payout 狀況」指官方明示的提款摩擦（等待期、盈利日、buffer、cap、split、KYC、支付渠道），不是付款可靠性保證。
>
> **自動化分類：** `允許` = 官方有正面條文；`限制` = 有明確禁止或重大限制；`未見限制` = 本次可讀官方規則沒有找到條文，**不是官方批准**；`未知` = 官方資料無法存取／不足。

## 先看：哪些規則資料最完整

這不是獲利推薦，而是「較適合繼續進一步核實」的資料品質排序：

1. **Ment Funding**：費用／通過／30 天 inactivity／EA／hedge／Forex、Futures、Equities 的規則相對完整。
2. **City Traders Imperium**：1-Step 的 fee、target、DD、payout 首次等待、EA、free trial 都可核實。
3. **Trade The Pool**：費用、通關、14-day demo、提款節奏與支付方式清楚；但第三方自動 copier 有明確禁令。
4. **Instant Funding**：One-/Two-Phase 的 target、DD、最少天數與多數 payout 等待期清楚；copy／reverse trading／group hedge 有限制。
5. **Fintokei**：StartTrader $5K 例的費用、三階段、180-day 上限、free trial、每兩週 payout 可核實；自動化／hedge 條文不足。
6. **Audacity Capital、Top One Trader、BrightFunded、ThinkCapital**：部分產品規則清楚，但仍有 payout 或 hedge／automation 細節缺口。

## 怎麼用這張表篩選，而不是被行銷用語誤導

1. **先刪除「未知太多」的平台。** WAF、404、只有 FAQ 索引或動態 checkout 不是小問題；它表示在你付款前無法審核核心條款。
2. **先選你的付款摩擦。** 要低頻／可等：Fintokei、Maven、PineX；要有明示頻率：Trade The Pool、Instant Funding、Ment、CTI、ThinkCapital。仍必須確認第一筆 waiting period、buffer、cap、KYC。
3. **自動化先選官方明示允許者。** 本矩陣中最明確為 Blue Guardian（CFD）、Alpha Capital（MT5 EA）、Ment Funding（Forex）、CTI（1-Step）、Top One（own EA）、Audacity（頁面級 EA/copy）。每個都有產品／策略範圍限制。
4. **hedge 是獨立問題。** 這次最清楚的正面資料是 Ment Funding 的 Forex；Instant Funding 對 reverse/group hedge 有禁令。其餘的 `—` 不是允許。
5. **free trial 不等於可出金。** FTMO、Trade The Pool、CTI、Fintokei、Audacity 有可確認的 trial/demos，但它們不會帶來 payout 資格。

## 購買前必須書面確認的 9 項

對每一家、每一個選定的 product／size／platform／stage，要求官方 support 或 compliance 書面答覆：

1. final checkout fees（一次性、月費、reset、activation、market data、commission、tax）。
2. pass steps／target／DD 起算與 trailing／daily reset／minimum days／consistency／time limit。
3. first and subsequent payout 的 waiting period、winning/Q days、minimum、cap、buffer、split、拒絕／審核條件。
4. KYC、稅表、居住國可用性與 payment rail。
5. 自寫、本人控制的 EA/bot/webhook/VPS 對該 stage 是否准許，以及 HFT／order rate／短持倉限制。
6. 同人多帳戶 copier、外部訊號、跨 firm copy 是否可用。
7. 同／跨帳戶的 opposite position、hedging 與相關商品風控是否可用。
8. inactivity 的定義、天數、警告、終止與已累積 profit 的處理。
9. trial 是否真的免費、是否需卡、到期後是否自動付費，以及是否與付費規則隔離。
