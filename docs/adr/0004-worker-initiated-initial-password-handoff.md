# Use worker-initiated initial password handoff

The worker operator enters the MT5 password locally during initial registration and, after a successful local login yields actual account and terminal evidence, sends it to the console through Cloudflare TLS. The console immediately stores the password in OpenBao and remains its sole authority; workers never directly access OpenBao or persist passwords. This replaces bootstrap grants because it avoids a second one-time credential lifecycle while retaining hardware-key proof, administrator review, IP rate limiting, and later per-login WSS credential mediation. Pending-registration secrets are deleted when the request expires or is rejected.
